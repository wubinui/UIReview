About

A faster way to review interfaces.

See what the browser sees

UIReview is a self-contained Chrome extension for inspecting layouts, comparing spacing, checking typography, and understanding the structure of a live interface without leaving the page.

Turn observations into feedback

Capture any region, annotate it with lightweight drawing tools, describe the issue, and send the complete context directly to a Feishu or Lark document in one flow.

Local by design

Inspection and screenshots are processed in the browser. UIReview has no cloud backend, and each user connects their own Feishu application when they choose to send feedback.
