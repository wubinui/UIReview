Start reviewing with UIReview.

Install

  1. Download UIReview and open chrome://extensions.
  2. Enable Developer mode, choose Load unpacked, and select the extension folder.
  3. Click the UIReview toolbar icon to open the floating review tools.

Inspect and compare

Press I and move across the page to inspect box model, layout, color, and typography values. Click an element to lock it, then hover another element to compare spacing. Press Space to fix the style panel for dragging, and press Space again to resume cursor following.

Screenshot feedback

Press C, drag over the region you want to capture, and release. Add pen, arrow, rectangle, or ellipse annotations, describe the issue, choose a destination, and send it directly to Feishu or Lark.

Commands

I
Inspect elements
F
Find by CSS selector
C
Capture screenshot feedback
T
Inspect typography
R
Show pixel rulers
X
Toggle X-ray view
P
Open the eyedropper
Esc
Close the current layer or collapse the toolbar

Connect Feishu

Create a self-built application in the Feishu Open Platform, add the required document and drive permissions, then enter its App ID and App Secret in UIReview settings. Credentials remain in local extension storage.
